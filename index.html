  3. 사진 앱에 저장을 누르고 공유 메뉴에서 이미지 저장 또는 비디오 저장을 골라요.
  4. 사진 앱에서 새로 저장된 항목이 바꾼 날짜 자리에 들어가 있어요. 예전 파일은 직접 지우면 돼요.
화질이 정말 그대로인가요?

네. 사진이나 영상을 다시 압축하지 않고, 파일 안에 적힌 날짜 글자만 고쳐요. 파일 크기도 거의 그대로예요.

파일이 어디로 올라가나요?

어디에도 올라가지 않아요. 모든 처리가 지금 보고 있는 브라우저 안에서 끝나요.
